# open.mp ModSync Client Distribution

**Version**: 0.4.0 - R1
**Credits**: eLdarqO

## How to Install
1. Copy the contents of this folder into your **GTA San Andreas** directory.
2. Run `install_mod_sync.bat`.
3. Double click `play_openmp.bat` or `ModSyncLauncher.exe` to launch and synchronize all mods!
